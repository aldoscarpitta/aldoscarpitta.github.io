⚙️ Setup Necessario

Per utilizzare questo motore di ricerca, devi configurare il Google Apps Script:

  1. Apri script.google.com
  2. Crea un nuovo progetto e incolla lo script
  3. Fai Deploy come Web App
  4. Copia l'URL e inseriscilo qui sotto nel codice alla riga SCRIPT_URL

Consulta il file SETUP_INSTRUCTIONS.md per la guida completa.
