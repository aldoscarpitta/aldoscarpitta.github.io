GitHub Sync

Calls are written to calls.json in your repo on every save.

When configured, every time you add, edit, or delete a call, the page silently commits calls.json to your GitHub repository. GitHub Pages then serves it at aldoweb.xyz/calls.json — readable by the weekly Cowork automation.

Create one at github.com/settings/tokens/new → select repo scope (or public_repo if the repo is public). The token is stored only in this browser's localStorage.
